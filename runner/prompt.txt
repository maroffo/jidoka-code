For each verified finding, score how safe it is to merge this PR with that issue unresolved. Use 90–100 for non-blocking impact, 60–89 for a confirmed regression that needs a fix before merge, and 0–59 for serious impact such as data loss, broken authorization, or a critical path failing. Choose the number using the documented impact and reach. Assess the risk introduced or worsened by this PR. An unrelated pre-existing issue alone does not block it. Jidoka uses the lowest verified score for the PR, or 100 when a complete review finds no issues.
